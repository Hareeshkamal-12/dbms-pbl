System Architecture & Setup

Execution commands, schema structure, and environment variables.

1

Quick Setup & Execution

Run these steps in your terminal to initialize and run the Flask backend with MySQL:

Terminal (Bash) 
# 1. Install required dependencies
pip install -r requirements.txt

# 2. Import schema into your MySQL server
mysql -u root -p < schema.sql

# 3. Launch Flask application
python app.py
Environment Variables: Configure these optional parameters:
  • DB_HOST: Hostname (default: localhost)
  • DB_USER: Database username (default: root)
  • DB_PASS: Database password
  • DB_NAME: Database name (default: student_portal)
  • SECRET_KEY: Session encryption key
2

Multi-Role Architecture

The system implements 3 distinct personas with dedicated responsibilities:

👑 Admin Institutional Admissions Student admissions, curriculum subjects, user accounts, and system configuration.
🍎 Teacher Classroom & Gradebook Daily attendance workstation, gradebook assessment, health alerts, and absence approvals.
🎓 Student Academic Self-Service Student ID badge, 75% exam eligibility gauge, official printable transcript, and absence notes.
